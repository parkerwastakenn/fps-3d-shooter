# 3D FPS Shooter

A first-person shooter game built with Three.js and Cannon.js physics engine.

## Features

- **3D Environment**: Full 3D gameplay with buildings and terrain
- **Physics**: Realistic gravity and collision detection
- **Enemy AI**: Enemies that spawn and chase the player
- **Combat System**: Shoot enemies to earn points
- **HUD**: Health, ammo, and score display
- **Controls**:
  - **WASD**: Move
  - **Mouse**: Look around
  - **Click**: Shoot
  - **Space**: Jump
  - **R**: Reload ammo
  - **Click on canvas**: Enable mouse lock

## How to Play

1. Open `index.html` in your web browser
2. Click on the game canvas to enable mouse look
3. Use WASD to move and mouse to aim
4. Click to shoot enemies
5. Survive as long as you can and rack up points!

## Installation

No installation required! Just open the HTML file in any modern web browser.

## Technologies

- **Three.js**: 3D graphics library
- **Cannon.js**: Physics engine
- **WebGL**: Hardware-accelerated graphics

## Game Mechanics

- Enemies spawn periodically and chase the player
- Each enemy killed grants 100 points
- Contact with enemies damages your health
- Limited ammo - reload with 'R' key
- Game ends when health reaches 0

Enjoy the game!
